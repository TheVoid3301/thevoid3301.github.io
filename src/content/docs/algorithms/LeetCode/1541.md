# 1541. 平衡括号字符串的最少插入次数

> **题目来源**：[LeetCode — 1541. 平衡括号字符串的最少插入次数](https://leetcode.cn/problems/minimum-insertions-to-balance-a-parentheses-string) · **难度**：Medium · **语言**：C++  

## 题目描述

给定字符串 `s`，其中仅包含 `(` 和 `)` 两种字符。

本题规定，一个合法的平衡括号字符串必须满足：

1. 每个左括号 `(` 都要匹配连续的两个右括号 `))`。
2. 匹配的 `))` 必须出现在对应左括号之后。

例如：

- 合法：`())`、`())(())))`、`(())())))`
- 不合法：`)()`、`()))`、`(()))`

你可以在字符串的任何位置插入左括号或右括号。

请计算最少需要插入多少个括号，才能使整个字符串满足上述规则。

## 示例

### 示例 1

**输入：**
```text
s = "(()))"
```

**输出：**
```text
1
```

**解释：**

字符串中有两个左括号，但只有三个右括号。还需要在末尾插入一个 `)`，得到 `(())))`。

### 示例 2

**输入：**
```text
s = "())"
```

**输出：**
```text
0
```

**解释：**

原字符串已经符合平衡规则，不需要插入任何字符。

### 示例 3

**输入：**
```text
s = "))())("
```

**输出：**
```text
3
```

**解释：**

在开头插入一个 `(`，并在结尾插入两个 `)`，共插入三个字符。

### 示例 4

**输入：**
```text
s = "(((((("
```

**输出：**
```text
12
```

**解释：**

共有六个左括号，每个左括号都需要两个右括号，因此需要补充十二个 `)`。

### 示例 5

**输入：**
```text
s = ")))))))"
```

**输出：**
```text
5
```

**解释：**

七个连续的右括号需要四个左括号与一个额外的右括号，最少插入五个字符。

## 提示

- `1 <= s.length <= 10^5`
- `s` 仅由字符 `(` 和 `)` 组成。
