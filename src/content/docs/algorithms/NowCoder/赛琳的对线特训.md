# A - 赛琳的对线特训

- **来源：** [牛客练习赛158 A. 赛琳的对线特训](https://ac.nowcoder.com/acm/contest/141876/A)
- **时间限制：** C/C++/Rust/Pascal 1 秒；其他语言 2 秒
- **空间限制：** C/C++/Rust/Pascal 256 MB；其他语言 512 MB

## 题目描述

赛琳想购买装备“高速弹”，需要花费 \(k\) 个灵魂。她初始拥有 \(0\) 个灵魂，对线期共有 \(n\) 波兵线。第 \(i\) 波结束后，她会获得 \(a_i\) 个灵魂。

她最多可以选择一波兵线，让队友青藤暂时离开，从而使这一波获得的灵魂翻倍，即将 \(a_i\) 变为 \(2a_i\)。

请计算她最早能在第几波兵线结束时买到装备。如果对线期结束后仍然买不起，输出 `-1`。

## 输入格式

第一行是测试数据组数 \(T\)，满足：

$$
1 \le T \le 10^4
$$

每组测试数据包含：

1. 一行两个整数 \(n,k\)，满足：

$$
1 \le n \le 2\times 10^5,\quad 1 \le k \le 10^{15}
$$

2. 一行 \(n\) 个整数 \(a_1,a_2,\ldots,a_n\)，满足：

$$
0 \le a_i \le 10^9
$$

保证所有测试数据的 \(n\) 之和不超过 \(2\times 10^5\)。

## 输出格式

每组测试数据输出一行：

- 如果能买到装备，输出最早满足条件的兵线波次。
- 如果始终买不起，输出 `-1`。

## 样例

### 输入

\`\`\`text
6
4 9
2 3 1 4
3 8
4 0 1
3 9
1 2 1
4 12
1 2 3 3
3 8
3 2 0
3 1
0 0 0
\`\`\`

### 输出

\`\`\`text
3
1
-1
4
2
-1
\`\`\`

## 样例说明

- 第 1 组：第 2 波将收益翻倍后，前三波累计获得 \(2+6+1=9\) 个灵魂，因此答案为 `3`。前两波最多只能获得 \(2+2\times3=8\) 个灵魂。
- 第 2 组：将第 1 波收益翻倍后，立即获得 \(8\) 个灵魂，因此答案为 `1`。
- 第 3 组：全部收益之和为 \(4\)，翻倍最多再增加 \(2\)，总计只有 \(6\)，无法购买装备。

## 解题思路

## C++ 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long t;
    long long n, k;
    cin >> t;
    for (long long p = 0; p < t; ++p) {
        cin >> n >> k;
        vector<long long> a(n, 0);
        long long l = 0, premax = -INT_MAX;
        bool f = false;
        for (long long i = 0; i < n; ++i) {
            cin >> a[i];
            premax = max(premax, a[i]);
            if (l + premax + a[i]>= k && !f) {
                cout << i + 1 << endl;
                f = true;
            }
            l += a[i];
        }
        if (!f) {
            cout << -1 << endl;
        }
    }
    
    return 0;
}
```
