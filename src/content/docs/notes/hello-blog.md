# Hello Blog：我的博客从这里开始

*2026 年 10 月 8 日 · 随笔*

> Hello, Blog!
>
> 这是我自2022年读大学以来, 第一次比较系统的撰写博客.

## 01 / 为什么想写博客？

我是一个懒蛋, 属于是那种即使被给予时代前例的天赋也会因为懒惰而荒废的那种懒蛋. 自2022年读大学以来, 我留给学习的时间非常非常少, 基本处于荒废的情况, 但是熟人的成就使得我开始焦虑, 我不想承认自己真的智商上不及他人, 所以以记录博客的方式, 督促我学习, 同时想要给自己证明以下, 我很聪明只是不想学(虽然我现在已经开始接收自己的平庸, 也许我真的智商不及他人吧😂).

**为什么不建立一个属于自己的技术博客，把这些知识系统地整理起来？**

我希望它不仅是一个存放笔记的地方，更是一个可以不断积累、更新和回顾的个人知识库.

## 02 / 从零开始搭建

经过一番了解，我最终选择了这套技术方案：

- **Astro + Starlight**：负责博客页面和 Markdown 文档管理.
- **GitHub Pages**：免费托管静态网站.
- **GitHub Actions**：在每次提交代码后自动构建和部署.
- **Markdown**：作为主要的文章编写格式.

我希望最终实现一种简单的工作流：

**Write Markdown → Git Push → Automatic Deployment**

这样以后就能把更多精力放在内容本身，而不是网站维护上.

## 03 / 这个博客以后会记录什么？

目前，我计划将内容分成几个方向.

**Algorithms**

记录数据结构、算法设计、编程竞赛和刷题思路.

**Infrastructure**

记录 CUDA、Triton、GPU 编程、大模型推理以及高性能系统相关知识.

**Projects**

记录源码阅读、工程实践、项目设计、遇到的问题和最终的解决方案.

**Research**

记录论文阅读、机器学习、模型设计和科研实验中的思考.

**Random Thoughts(Note)**

当然，也需要一个不那么严肃的角落.

这里可以放一些生活记录、日常感想，或者偶尔的碎碎念.

## 04 / 写在最后

我不知道这个博客最终会积累多少篇文章，也不知道多年之后再回头看，这些内容会显得多么基础.

但我希望自己能够保持好奇心，持续学习，也持续记录.

不必每一篇文章都很完美，也不必每一次探索都有结果.

重要的是，今天比昨天多理解了一点.

最重要的是, 我需要一个情感寄宿或者宣泄的地方, 来缓解我的焦虑, 接受自己的平庸.

**Stay curious. Keep building.**
